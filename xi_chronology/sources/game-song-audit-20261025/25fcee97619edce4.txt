SEVEN's CODE -Special Music Collection-
SEVEN's CODE ZEROについては、Webラジオもまとめる意図から独立ページに切ります → SEVEN's CODE ZERO
このページは、基本的には公式名義で音源配信（もしくは販売）する取り組みをまとめることを目的としています
非公式を含めた音源情報一般（およびその入手方法）をお求めの方には、外部にある音源購入情報のほうをおすすめします
公式音源  †
YouTubeの公式チャンネルおよび音楽配信サービスにて、UNLIMITED STUDiO および Felion Inc. の公式名義で配信されている音源の情報を公開日とともにまとめています
一般販売されているボイスドラマシリーズ「SEVEN's CODE ZERO」（6作リリース）への収録状況もあわせて扱います
第三者（作者自身も含む）によるものはすべて無視します
YouTubeへ投稿されなかった他社IPの音源を除き、基本的に外部提供曲（いわゆる版権曲）かどうかを区別しません
時間表記が 赤字 のものはYouTube公開音源よりも20%以上尺が長くなっている（いわゆるロング尺とみなせる）音源です
投稿し直しや、非公開の時期があったものもあるため、実際の公開日と一致させていない場合があります
音楽配信欄のリンクはBIG UP!で管理されている楽曲ページへそれぞれ張っています
各ページには実際に配信されているサービスの一覧が掲載されています（サービスによっては音源への個別リンクもあり）
公開後になくなってしまったページへのリンクは外してあります。ページがなくなった該当曲は後に配信そのものも停止されました
音楽配信欄の日付はSpotifyから取得した情報をあてはめています。実際に最初に聴くことができた日とは異なる場合があります
買い切り型での提供もあるため、公式でなされた「サブスクリプション配信」の表現を意識的に扱わないようにしています
Felion Inc.名義の HALZiNA Weiß 曲は BIG UP!経由の配信ではないので、配信日のみ記載
