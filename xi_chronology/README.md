# xi年表調査データ

公開用本文は `data/public_annotations.json`（曲解説43件）と `data/public_collection_annotations.json`（収録先72件・曲目312件の説明）へ分離した。承認済みの感想・制作意図・公開出典を保持し、調査コメント・入力履歴・人物照合メモを自動でサイトへ流さない。新しい本文はこれらの公開用ファイルでレビューし、元の調査資料と承認記録はそのままローカルに保持する。

最初に「照合結果.md」を参照してください。原本・主台帳・掲載原稿は別々に保管しています。

JSONを主データとし、CSVはExcelで閲覧できるUTF-8 BOM付きのスナップショットです。配列・複数URLはCSV内でJSON文字列として保持します。日付不明は空欄／nullとし、便宜的な月日を補いません。

初期照合後の新曲は`data/additional_works.json`、その出典・公開履歴は`data/research_additions.json`に追加します。元251項目の照合スナップショットは保持し、サイト書き出し時に統合します。2026年10月26日にXI-252・XI-253を追加しました。X発表日と初公開日が同日という利用者補足に基づき、この2曲は初公開日も登録しています。X投稿の確認記録は`sources/new-releases-20261026/x-post-checks.json`です。

曲への感想は新しい曲から順に利用者本人に確認します。曲名・ゲーム名などの略記や誤記は、こちらで正式表記を確認して整えます。必ず清書案をチャットに提示し、利用者のOKをもらってから登録します。承認前は`status: draft`で保持し、公開データへ出しません。ParallaxとRe：End of a Dream (Diceros Bicornis Remix)は利用者が未聴のため、感想を保留しています。調査上の事実を記した既存の`comment`と、利用者の感想は混同しません。

感想の原文・掲載文・時刻メモ・未聴保留は`data/listener_comments.json`に保存します。公開書き出しでは「感想：」と明示し、既存の調査メモがある場合は両方を区別して掲載します。担当推測や他曲との類似は聴いた印象として保持し、帰属・公開履歴・クレジットには反映しません。

承認された本文は、楽曲詳細の冒頭に「補足コメント」として段落付きで掲載します。感想に限らず利用者の補足評論も扱います。データを書き出した後、起動中のAPIが旧データを読み続けている場合はプレビューを再起動して表示を確認します。

補足コメント本文のアーティスト名は敬称略で統一します。氏・さんなどは付けず、正式な名義の綴りを確認します（例：CHUBAY）。引用文は原文の表記を保持します。

補足コメントに登場する登録済み楽曲の正式名・別名は、公開書き出し時に楽曲詳細へのリンクを付けます。本文は変更せず、同名候補が複数ある名前と掲載曲自身は自動リンクしません。特定の版や「嵐の前触れ」などの任意の語句は、本文で`[表示文](/works/XI-161)`のように指定できます。未登録曲は本文のまま残します。画面では内部楽曲リンクとHTTPS出典リンクのみを解釈し、HTMLは解釈しません。

初期251項目の日付確認は初公開日の確定を意味しません。これらの初公開日は未確定のためnullです。作曲年を本人説明で確認できた曲は、年だけを保持し、精度をyearと記しています。

publication_eventsのis_publication_recordがfalseの記録は、作曲・リマスターの実施年です。公開年表のソートには使いません。家族関係family_idは便宜的なグループIDで、独立した新規作曲数は確定していません。

作者が示した読み方は`data/work_pronunciations.json`に、対象ID・読み・提案か確定指定か・投稿日・出典URL・確認日を保存します。未確認の読みは推測で埋めず、曲名や別名へは混ぜません。Zauberkugel、Niflheimr、Parousiaは本人の提案調の投稿として保持しています。元投稿の取得記録は`sources/identity-reaudit-20261030/`と`sources/user-followups-20261030/`に保存しています。
