# 年選択・追従バー案

- ブランチ: `feat/floating-year-bar`
- 比較の起点: `966ebeb`（dev）
- プレビュー: http://127.0.0.1:3211/
- 対案: http://127.0.0.1:3212/ （`feat/year-drawer`）

幅760px以下で、元の横並びの年選択が画面上へ抜けると、年選択バーだけが上端へ追従する。表示は280msで上から滑り込む。元の年選択まで戻ると追従バーは隠れる。デスクトップは従来の左側ナビゲーションを維持。

年を選ぶと既存の条件で絞り込み、取得後の結果先頭へ移動する。選択済みの年は横方向に表示位置を合わせる。追加ライブラリは使わず、IntersectionObserverとCSSで実装。動きを減らす設定では既存の`prefers-reduced-motion`ルールと即時スクロールを使う。

## 確認

- TypeScriptとNext.js本番ビルド通過。
- Chromiumの390px縦画面で、スクロール後も上端から年を選択可能。2023年の4件と日付未確認112件への切り替えを確認。
- 1280pxで従来の左側ナビゲーションを確認。横はみ出しなし。
- 追従バーのボタンは高さ44px以上。
- バックエンドのデータ形式、元資料、検索・無限スクロールの取得処理は変更していない。
- 証跡: `verification/xi-floating-year-bar.png`。

実機のiOS Safariでのタッチ操作と、OSの動きを減らす設定を切り替えた実行確認は未実施。スクリーンショットはChromiumの幅変更による確認。

## 採用・ホイール対応（2026-10-24）

利用者がこの案を採用。追従バーと元の横並びバーに、縦ホイールを横移動へ変換する操作を追加した。下方向で右、上方向で左へ動く。左右の端ではページの縦スクロールを妨げない。横方向のトラックパッド入力、Shift+ホイール、Ctrl+ホイールは標準動作を維持する実装。

Chromiumの337px幅でホイール操作を確認。追従バーの横位置は0→442→221pxと動き、その間のページ縦位置は1300pxのまま。右端1185pxでさらに下方向に操作するとページ縦位置が1742pxへ進む。元の年バーも横位置442pxへ動き、ページ縦位置0pxを保持。本番ビルド・型チェック通過。

追加の確認記録は`verification/xi-year-bar-wheel.json`、画像は`verification/xi-year-bar-wheel.png`。この変更を含めてdevへマージする。alpha・mainへの昇格、公開は別の区切りで行う。
