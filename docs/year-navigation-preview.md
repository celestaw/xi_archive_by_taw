# 年選択・左パネル案

- ブランチ: `feat/year-drawer`
- 比較の起点: `966ebeb`（dev）
- プレビュー: http://127.0.0.1:3212/
- 対案: http://127.0.0.1:3211/ （`feat/floating-year-bar`）

幅760px以下で年の横並びを「年を選ぶ」ハンバーガーボタンに置き換える。見出しとボタンの帯は上端へ追従する。押すと年ボタンが2列に並ぶパネルが左から280msで開き、180msで閉じる。デスクトップは従来の左側ナビゲーションを維持。

パネルはブラウザー標準のdialogを使い、背後のスクロールを止める。閉じるボタン・背景・Escで閉じられ、通常の閉じ操作では開くボタンへフォーカスが戻る。年を選ぶと閉じて対象の取得後の結果先頭へ移動する。動きを減らす設定では既存の`prefers-reduced-motion`ルールと即時の閉じ・スクロールを使う。

## 確認

- TypeScriptとNext.js本番ビルド通過。
- Chromiumの320px・390px縦画面で横はみ出しなし。年の選択、日付未確認112件への移動を確認。
- 1280pxでボタンを隠し、既存の左側ナビゲーションを表示。
- Escで閉じると開くボタンへフォーカスが戻る。Tabでパネル内のボタンへ移動可能。
- `q=Long`の検索条件を保持した2019年の3件への切り替えと、ブラウザーの戻るを確認。
- ライト・ダーク両テーマの表示を確認。パネル内の年ボタンは高さ44px以上。
- データ形式と元資料は変更していない。
- 証跡: `verification/xi-year-drawer.png`。

実機のiOS Safariでのタッチ操作と、OSの動きを減らす設定を切り替えた実行確認は未実施。スクリーンショットはChromiumの幅変更による確認。
