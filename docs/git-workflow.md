# ブランチ運用

- `dev`: 採用した変更を統合する。
- `alpha`: `dev`から公開前の確認対象を取り込む。
- `main`: `alpha`で確認したコミットを取り込み、公開に使う。
- `feat/floating-year-bar`: 縦画面で年選択バーが画面上端に追従する案。
- `feat/year-drawer`: 縦画面でボタンから左の年選択パネルを開く案。

機能の比較は同じ`dev`の状態から分岐して行う。選ばれた案だけを`dev`へマージし、`dev → alpha → main`の順で進める。ブランチ作成やマージだけではデプロイしない。

初期状態として、既存の`master`を`dev`へ改名する。初回保存の`ec60d86`を`dev`・`alpha`・`main`の共通の起点とする。リモートと自動デプロイはまだ設定していない。

比較用の作業ディレクトリは`.worktrees/`、ローカル実行ログは`.local-preview/`に置き、コミットしない。
