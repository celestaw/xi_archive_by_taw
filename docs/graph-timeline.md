# グラフ年表（2026-10-31改訂）

`/timeline`をメインナビゲーションの「グラフ年表」から開く。確認できた最古の公開記録で上から古い順、同日は作品ID順に、1曲1行で並べる。

## 表示と操作

- 行間は16pxが既定。24px・32pxへ変更できる。左の曲名列と横方向の行罫線は置かず、点と線で密度を保つ。
- 初期表示は画面幅に合わせて全期間を見渡す。横軸は1年600px・1200px・2400pxにも拡大でき、拡大時は先頭曲の公開時期付近から始まる。「年へ移動」で該当年の曲へ進む。
- 線と丸を含む各曲の領域は作品詳細へのリンク。ホバー・フォーカスで曲名、公開記録、現在の音源と出典を表示する。クリック・Enterは詳細へ進み、上下矢印キーは前後の曲へ移動する。Escapeでポップアップを閉じて元のリンクへ戻る。
- 曲名・別名の検索、仮公開の有無、聴ける音源あり／公式／非公式／音源未確認の絞り込みに対応。日付未確認はグラフ下の一覧に分け、読み込み中・0件・通信失敗を区別する。

## 点と線の意味

- 現在の音源が未確認・公開終了の場合は、最初の公開記録と現在を白丸で示し、その間を点線にする。過去のゲーム収録歴や終了した筐体の記録だけで黒丸・実線へ変えない。
- 現在聴ける掲載先と有日付の全曲公開記録がある場合は、その公開時点を黒丸、そこから現在の黒丸までを実線にする。先行する仮公開等の白丸から本公開までは点線。ただし、年・月の精度から分かる両記録の期間が重なる場合、その間の点線は引かない。
- 掲載先はあるが全曲公開日を確認できない場合は、本公開日を補わず点線を保つ。現在の丸のみ塗りつぶす。黒丸・実線はテーマの本文色を使う。
- 年・月だけの日付は既知期間の中央へ配置し、架空の月日を表示しない。制作年は公開日に使わない。日付は最古の確認記録であり、真の初公開日とは限らない。
- 「現在」はAPIの日本時間の基準日。実線も過去から一度も途切れず聴けたことの証明ではない。音源未確認は、聴けないと確定した意味ではない。

## 音源掲載と補足データ

利用者の表示方針に従い、YouTube・SoundCloud・発売済みアルバム・公式配信サービス等の全曲掲載を聴取可能として扱う。実再生・地域制限は未検証。プレビューや抜粋は全曲掲載に含めず、公式・非公式はポップアップと絞り込みで区別する。アルバム収録は現在の新品販売や無料配信の確認を意味しない。

`site/backend/data/audio_sources.json`は18作品・18音源・20件の有日付記録を補足する。公開用モデルで検証し、重複作品ID・未知の作品IDを拒否する。音源の発見で作品の帰属判定を昇格させない。

- Minerva・SuddeИDeathの個人投稿は非公式。Xeno GravityはKONAMI公式CDの収録情報を公式音源として扱う。
- Parallaxは2026-10-24の仮公開から2026-10-30の公式全曲掲載へ進む記録を保持する。

青いヘッダー、ライト／ダークのテーマ変数、書体、控えめな見出しは既存の[視覚方針](visual-direction.md)を継承する。今回の確認はソースとデータに限定し、ブラウザ操作が無効のため現行画面の表示・操作は未確認。
