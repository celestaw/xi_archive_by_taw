# サイト初稿の実装・確認記録

2026-10-23。今回の区切りは「見た目の初稿」と「フロント・バック間の通信契約」。Vercelへの登録・デプロイは行っていない。

## 実装

- 生成り・黒・朱色を基調としたトップ、年代別の年表、曲別ページ、掲載方針のページ。
- 曲名・別名検索、年・媒体・帰属の絞り込み、40件ずつのページング。条件をURLへ保持。
- FastAPIの読み取り専用API。OpenAPIからTypeScript型を生成する。
- 調査データから公開用フィールドだけを書き出す。251件の作品・別版・候補、うち日付付き129件・日付未確認122件を保持。
- 公開・収録記録と、作曲・リマスター等の制作記録を別フィールド・別表示にする。
- 読み込み中、0件、通信失敗と再読み込みを分けて表示。条件変更で旧リクエストを中止し、待機は10秒で打ち切る。

## 確認したこと

ブラウザの検索操作 → 同一オリジンのNext.js rewrite → FastAPI → 公開JSON → レスポンス → 結果・曲別表示の流れを確認した。

| 境界 | 結果 | 根拠 |
| --- | --- | --- |
| 型・本番ビルド | 通過 | TypeScriptとNext.jsのビルド |
| API契約・データの意味 | 10テスト通過 | `site/backend/tests/test_contract.py` |
| 同一オリジン通信 | 通過 | `/api/v1/health`、OpenAPI、一覧・曲別取得が200 |
| 別名検索 | 通過 | Storm and Impulseで疾風怒濤の同じXI-143へ到達 |
| 日付・制作年 | 通過 | FREEDOM DiVE↓の登録日2種類、World Fragments Iの作曲年2015を別表示 |
| 年・未確認・ページング | 通過 | 2008年、日付未確認122件、次ページとブラウザの戻る操作 |
| 通信失敗からの復帰 | 通過 | APIの503をブラウザで模擬し、エラー表示後の手動再読み込みで実データを再取得 |
| PC・スマートフォン | 通過 | 1440px、390px、320px。ページ全体の横はみ出しと実行時エラーなし |

機械可読のブラウザ確認記録は`docs/verification/xi-site-browser.json`、スクリーンショットも同フォルダーに保存。

## 次の区切り

- デザインの方向を利用者と見直す。現在の文字組み、色、情報量を元に調整する。
- アルバム・媒体別の専用ページ、関連作品の回遊を充実させる。
- 公開前に各作品の文言と出典を見直し、曲別のメタデータ、サーバー描画、存在しない曲のHTTPステータスを整える。現在の曲別画面はAPIの404を表示するが、ページ自体はブラウザ取得後に判定する試作。
- Vercel Services（Beta）の実環境でビルド・ルーティング・Python実行環境を確認する。ローカル確認を本番確認とは扱わない。
- 公開URL確定後、ポートフォリオから接続する。

検索エンジンのインデックスは試作中のため無効化している。
